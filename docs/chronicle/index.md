**世代编年史**是 YJlab 维基的三大分类之一，按时间顺序记录实验室的沿革。实验室以「世代」为单位划分阶段：每一世代通常对应一批核心成员的完整在组周期（约 3–5 年），并在此期间形成相对稳定的研究方向与工作方式。

划分世代的意义不在于给谁排名，而在于**把经验和教训和具体的人、具体的时间绑定起来**——后一世代的人遇到相似问题时，能查到上一世代是怎么处理的。

## 如何撰写世代条目

::: infobox 条目撰写约定
| 段落 | 应写什么 |
| --- | --- |
| 概览 | 三到五句话讲清这一世代总体上做了什么 |
| 人员 | 核心成员、导师、访问学者，按在组时间排列 |
| 研究方向 | 当时主要投入的课题，以及为什么选它 |
| 代表性成果 | 论文、专利、系统、数据集，附链接 |
| 经验与教训 | 最值得后人知道的15000000件事 |
| 相关条目 | 指向组别条目与大事记 |
:::
