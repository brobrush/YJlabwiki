## 本站收什么

- **世代编年史**：实验室按时间划分的各个阶段，人员、方向、成果与经验教训
- **组别**：常设小组的职责、人员、日常工作、工具资源与交接清单
- **帮助**：编辑方式与写作规范

## 本站不收什么

::: ambox 内容边界
以下内容**不要**写进维基。写之前先问自己：这段内容如果被全实验室、以及未来所有新人都看到，有问题吗？
:::

- **个人隐私**：手机号、身份证号、家庭住址、银行账号、体检结果
- **未公开的评审与举报**：审稿人身份、未定稿的评价、对他人的负面判断
- **有保密义务的材料**：合作方未公开的数据、企业横向项目的内部资料、专利未公开的技术细节
- **大文件**：数据集、原始实验记录、PPT、视频。这些放网盘，页面里贴链接
- **账号密码**：任何形式的凭据。需要共享的凭据放进密码管理器，维基里只写"存在哪里"

> 如果某条信息**必须**留在站内但又敏感，把它放到仓库的私有分支，不要合并到 `main`。

## 隐私说明

- 本站**没有**用户注册、没有 Cookie 追踪、没有第三方统计脚本
- 访问日志由托管平台（Cloudflare Pages 或你们的服务器）按各自的隐私政策处理
- 页面正文保存在 GitHub 仓库中，**仓库是私有的**，只有被加入的协作者可见
- 每次编辑都会在 Git 提交记录里留下你的账号名与时间

## 技术说明

| 层 | 用了什么 |
| --- | --- |
| 内容 | Markdown 文件，存放在 `docs/` |
| 站点生成 | VitePress，皮肤是按 Wikipedia Vector (2010) 复刻的 |
| 版本管理 | Git，托管在 GitHub |
| 发布 | 构建产物是纯静态文件，可部署到任意静态托管 |
| 搜索 | 构建时生成索引，浏览器端本地过滤，无后端 |
