## 新增一件工具

1. 在 `docs/tools/` 下新建一个文件，文件名用英文，例如 `example.md`
2. 头部写 frontmatter：

```yaml
---
title: 工具名
categories:
  - 工具介绍
---
```

3. 按上面的结构写正文
4. 在 `docs/.vitepress/config.mts` 的 `SIDEBAR` 里加上一行：
   `{ text: '工具名', link: '/tools/example' }`
5. 回到本页，在「工具一览」表里补一行

## 一个工具页面该写什么

::: infobox 建议结构
| 段落 | 写什么 |
| --- | --- |
| 用途 | 这件工具解决什么问题，什么时候该用它 |
| 使用前准备 | 防护、环境、前置检查 |
| 操作步骤 | 分步骤写，写到"新人照着做不会错"的粒度 |
| 安全须知 | 禁区与后果，写清"为什么不能这么做" |
| 常见错误 | 现象 → 原因 → 正确做法 |
| 存放与归还 | 放在哪、用完怎么处理 |
| 报修 | 坏了找谁、怎么描述问题 |
:::

这只是建议 —— 哪一节用不上就删掉，需要新的就加。
