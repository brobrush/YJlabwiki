**组别**是 YJlab 维基的两大分类之一，描述实验室的横向结构：谁负责什么、组与组之间怎么交接、每个组的规范和常用资源在哪里。

世代编年史回答"实验室**过去**是什么样"，组别条目回答"实验室**现在**怎么运转"。两者互相引用：组别条目里的历史沿革指向世代条目，世代条目里的人员分工指向组别条目。

## 如何撰写组别条目

::: infobox 条目撰写约定
| 段落 | 应写什么 |
| --- | --- |
| 职责 | 这个组对实验室负责交付什么 |
| 人员 | 现任与历任负责人，按时间排列 |
| 日常工作 | 例会节奏、交付物、验收标准 |
| 工具与资源 | 仓库、服务器、账号、文档的位置 |
| 交接清单 | 新人接手必须知道的五件事 |
| 相关条目 | 指向其他组别与世代条目 |
:::
