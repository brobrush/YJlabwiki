**YJlab 维基**是 应急科技创新实验室的过去和历史与传说，由实验室成员共同撰写与维护。本站收录实验室自成立以来的**世代编年史**，以及各**组别**的人员、方向、规范与成果，目标是把口口相传的经验沉淀成可检索、可追溯、可交接的文本。

实验室成员可以点开页面右上角的「**编辑**」标签直接修改正文；每一次改动都会被完整记录下来，可以随时对照与回退。
